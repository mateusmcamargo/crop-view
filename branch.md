Integração Contínua é uma prática de desenvolvimento de software onde os programadores consolidam suas alterações de código em um repositório central várias vezes ao dia. Cada envio aciona compilações e testes automatizados para detectar erros rapidamente. Nesse processo, as branches (ramificações) servem para isolar o desenvolvimento de novas funcionalidades ou correções, garantindo que o código em produção permaneça estável enquanto as mudanças são testadas em paralelo. Por fim, o Pull Request (PR) é a peça-chave que conecta essas duas pontas: ele funciona como um convite oficial para revisar, discutir e aprovar as alterações da branch antes que elas sejam integradas ao código principal, garantindo a qualidade e o alinhamento da equipe
