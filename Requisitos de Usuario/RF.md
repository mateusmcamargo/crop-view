# Requisitos Funcionais (RF)

RF01 - O sistema deve permitir a visualização dos talhões da plantação.

RF02 - O sistema deve permitir o cadastro de pragas e doenças.

RF03 - O sistema deve permitir o registro de eventos relacionados à plantação.

RF04 - O sistema deve exibir relatórios de monitoramento da saúde da cultura.

RF05 - O sistema deve apresentar um mapa interativo com os talhões.

RF06 - O sistema deve permitir interação com os dados apresentados.
