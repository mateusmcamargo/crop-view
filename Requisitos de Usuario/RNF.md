# Requisitos Não Funcionais (RNF)

RNF01 - O sistema deve ser responsivo, funcionando em dispositivos móveis e desktop.

RNF02 - O sistema deve ter bom desempenho no carregamento das páginas.

RNF03 - O sistema deve ser desenvolvido utilizando Next.js e TypeScript.

RNF04 - O sistema deve possuir interface amigável e intuitiva.

RNF05 - O sistema deve garantir segurança básica dos dados.
